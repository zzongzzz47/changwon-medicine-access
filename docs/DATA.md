# 데이터 준비와 재현 범위

| 자료 | 제공처와 용도 |
|---|---|
| 폐의약품 수거함 | 전국폐의약품수거함표준데이터, 기존 시설 위치 |
| 편의점 후보 | 소상공인시장진흥공단 상가(상권)정보, 2026-06-30 |
| 인구와 경계 | SGIS 2024년 인구 및 2025년 공간 경계 |
| 연령별 인구 | 읍면동별 고령인구 비중 진단 |

상세 수집 출처는 `source_manifest.json`과 보고서 참고문헌에 있습니다. SGIS 자료는 직접 신청한 이용조건을 따라야 하므로 원본 격자와 연결된 인구 파일은 재배포하지 않습니다.

최종 계산에는 `code/data/processed/demand_100m.csv`, `convenience_candidates_spatial.json`, `changwon_spatial.gpkg`와 기존망 진단 결과 등이 필요합니다. 입력을 준비한 후 코드 안내 순서대로 생성합니다. 공개한 집계 결과만으로 전체 공간 최적화를 재실행할 수는 없습니다.
